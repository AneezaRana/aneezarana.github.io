# 3D animated Portfolio

A React 3D animated Portfolio
 — a professional Frontend developer portfolio with animations, 3D elements, dark theme, and modern UI.

## Features

- **Preloader** — greeting animation (Salam, Hello, Hola…)
- **Custom cursor** — pink/blue glow trail
- **Hero** — particle canvas, typewriter roles, gradient orbs, avatar
- **About** — profile card, stats, bio
- **Skills** — infinite marquee with tech icons
- **Projects** — featured work cards
- **Experience** — scrolling cards + timeline
- **Testimonials** — reverse marquee carousel
- **Contact** — form with service dropdown
- **Music player** — floating play button (UI only)

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Customize

Edit `src/data/portfolioData.js` to change name, bio, skills, projects, experience, and social links.

Replace `public/avatar.svg` and `public/profile.svg` with your own images.

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS 4
- Framer Motion
- React Icons (Simple Icons)
